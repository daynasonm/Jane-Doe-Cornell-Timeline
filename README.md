# Jane Doe Cornell Timeline

Static website for GitHub Pages. Serve this folder with any static web server.

No API keys, paid services, server endpoints, databases, or live API requests are included. The reading guides offer only saved, clickable questions and answers. Public pages and their saved assets can be downloaded. Outbound source links open only when selected.

The timeline is a saved reporting snapshot with its check date shown; it does not update automatically. Squirrel maps use saved boundaries and available source points; live street tiles and observation searches are omitted.

Original reporting, dataset, photograph, audio and dependency credits remain in the page and assets. Their original licenses and attribution requirements apply; no blanket license is granted over third-party material.
